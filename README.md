# zxgk-scraper
⚖️ 中国执行信息公开网油猴脚本 (Zxgk Scraper)
🌟 主要功能特性
📊 弹窗深度解析：支持点击“查看”按钮后，自动打开同页详情弹窗，并精确提取渲染后的文本信息（如性别、身份证号/组织机构代码、执行法院、执行标的等）。

🛡️ 验证码智能容错：在抓取过程中若触发“请完成安全验证”弹窗，脚本将自动暂停，交由人工手动点选验证，验证通过后无缝自动恢复。

⏳ 随机降速防风控：内置随机等待延迟（2秒~4秒），模仿真人操作频率，有效降低高频点击触发反爬机制的概率。

📥 一键导出 CSV：自动过滤无用列，生成结构清晰、带 UTF-8 BOM（Excel 打开不乱码）的标准 CSV 表格文件。

🔄 防污染状态清理：每条数据提取完成后强制重置并关闭弹窗，杜绝数据串行与缓存污染。

📦 安装与使用指南
1. 前置准备
确保您的浏览器（如 Chrome、Edge、Firefox 等）已安装 Tampermonkey（油猴） 插件。

2. 安装脚本
点击浏览器右上角 Tampermonkey 图标，选择 “管理面板”。

点击 +（添加新脚本） 标签页。

将项目中的 script.js 源码完整复制并粘贴到文本框中。

按 Ctrl + S（Mac上为 Cmd + S）保存脚本。

3. 操作步骤
打开 中国执行信息公开网（被执行人查询页）。

输入查询条件并完成初始查询，页面下方出现结果表格。

网页右下角会出现 “📊 弹窗抓取 (渲染文本解析版)” 悬浮控制面板。

勾选 “自动打开弹窗并提取详情”，点击 ▶️ 开始抓取当前页 即可。

抓取完成后，点击 📥 导出 CSV 表格 保存数据。
